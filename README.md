# MusicChatApp
This will be an app that matches you with another person based on your music taste, and lets you talk to them in a chatroom


You will be able to:
register
login
select whether you want to be matched on top 5 songs
select the top 5 you picked
be matched with another user based on how similar your top 5 was to them
have a chatroom with them!
Groupchats + blocking also available
